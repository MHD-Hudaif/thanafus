# Static front-end copy

This folder is a standalone copy of the current Kauzariyya front-end design. It uses only HTML, CSS, JavaScript, and local media assets. The sample public content is embedded directly in `main.js`, so no PHP, API, React, build tool, or package installation is needed.

Open `index.html` directly in your browser (double-click it). No localhost or web server is required.

Navigation, schedule tabs, search fields, rating controls, and the page design work directly in the browser. Admin/API updates remain intentionally unavailable in this static copy.
